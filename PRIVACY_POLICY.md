# Privacy Policy

**Last updated:** 2026-01-24

## Summary
Text Learner processes text you select on a webpage (or detected question text) and sends it to the AI provider you configure (Groq, Google Gemini, or OpenAI). The extension does **not** send any data to the developer’s servers.

## Data Collected
- **Selected text / detected question text**: Sent to your chosen AI provider for processing.
- **API keys**: Stored locally in Chrome storage on your device.
- **Settings**: Stored locally in Chrome storage on your device.

## Data Not Collected
- No browsing history is collected or transmitted.
- No analytics or tracking is performed.
- No personal data is sent to the developer’s servers.

## Data Sharing
- Data is shared **only** with the AI provider you select for the purpose of completing the requested processing.
- The extension does not share data with any other third parties.

## Data Storage
- API keys and settings are stored locally in Chrome storage on your device.
- The extension does not store data on any external servers.

## User Control
- You can remove API keys or reset settings at any time from the extension options page.
- You can uninstall the extension to remove all stored data.

## Contact
If you have questions about this policy, contact the developer via the Chrome Web Store listing or the repository contact details.
